# Памятка: Google Search Console и Яндекс.Вебмастер

Настройка поисковых панелей для `kotcode.dev`. Делается один раз после
деплоя на прод; дальше — периодические проверки.

## 0. Предусловия

- Сайт открывается на `https://kotcode.dev` (прод-деплой прошёл).
- Подтверждение прав вшито в код: мета-теги подставляются из переменных
  `GOOGLE_SITE_VERIFICATION` и `YANDEX_VERIFICATION`
  (`src/app/layout.tsx` → `metadata.verification`).
- `robots.txt` и `sitemap.xml` уже отдаются:
  - `https://kotcode.dev/robots.txt` (со ссылкой на sitemap и `host`),
  - `https://kotcode.dev/sitemap.xml` (4 URL: главная + 3 страницы услуг).

Общий принцип подтверждения через мета-тег:
1. В панели выбираешь способ «HTML-тег» / «Мета-тег» и копируешь значение
   `content="…"` (только сам токен, без всего тега).
2. Кладёшь токен в **Vercel → Settings → Environment Variables** (Production).
3. **Redeploy** последнего прод-деплоя (переменные вшиваются в билд).
4. Возвращаешься в панель и жмёшь «Подтвердить».

Проверить, что тег появился (после redeploy):
```bash
curl -s https://kotcode.dev | grep -E 'google-site-verification|yandex-verification'
```

## 1. Google Search Console

Панель: https://search.google.com/search-console

### Добавление и подтверждение
1. «Добавить ресурс» → тип **URL-префикс** → `https://kotcode.dev`.
   (Не «Домен» — тот способ требует DNS-записи; мета-тег проще.)
2. Способ **«HTML-тег»** → скопировать значение `content="…"`.
3. Vercel → env `GOOGLE_SITE_VERIFICATION` = токен (Production) → **Redeploy**.
4. «Подтвердить».

### Sitemap
- Раздел **Sitemaps** → добавить `sitemap.xml` → «Отправить».
- Через пару дней проверить статус «Успешно», число обнаруженных URL = 4.

### Индексация
- **Проверка URL** (строка сверху): вставить `https://kotcode.dev/landing`,
  затем «Запросить индексирование». Повторить для остальных страниц услуг.
- Раздел **Индексирование → Страницы**: следить, что страницы попадают в
  «Проиндексировано», а не «Обнаружено / не проиндексировано».

### Что смотреть дальше (раз в 1–2 недели)
- **Эффективность** — по каким запросам показы/клики, средняя позиция.
  Отсюда берутся идеи для новых страниц и правок текстов.
- **Улучшения → Товары / Часто задаваемые вопросы** — Google подтянет
  нашу разметку `Offer` и `FAQPage`; смотреть, что нет ошибок.
- **Основные интернет-показатели (Core Web Vitals)** — должны быть «Хорошо».

### Про регион (важно для `.dev`)
Ручной выбор страны в Search Console убрали в 2022. Домен `.dev` — общий
(не ccTLD вроде `.by`), поэтому географию Google выводит из сигналов:
язык `ru`, упоминания Бреста, разметка `LocalBusiness` с адресом/гео,
кейсы на `.by`. Всё это в коде уже есть. Дополнительно локаль усиливает
Google Business Profile (см. отдельную памятку по картам).

## 2. Яндекс.Вебмастер

Панель: https://webmaster.yandex.ru — для СНГ критично, Яндекс тут силён.

### Добавление и подтверждение
1. «Добавить сайт» → `https://kotcode.dev`.
2. Способ **«Мета-тег»** → скопировать значение `content="…"`.
3. Vercel → env `YANDEX_VERIFICATION` = токен (Production) → **Redeploy**.
4. «Проверить».

### Sitemap
- **Индексирование → Файлы Sitemap** → добавить
  `https://kotcode.dev/sitemap.xml`.

### Регион (в отличие от Google — задаётся руками, заметно помогает)
- **Информация о сайте → Региональность** → регион **Брест**.
  Подтверждение региона может потребовать привязки к Яндекс.Бизнесу —
  см. памятку по картам/бизнес-картам.

### Связка с Метрикой
- Счётчик Метрики уже стоит (`NEXT_PUBLIC_YANDEX_METRICA_ID`).
- В Вебмастере связать сайт с этим счётчиком — ускоряет обход и даёт
  данные о поведении.

### Что смотреть дальше
- **Индексирование → Страницы в поиске** — сколько страниц в индексе (ждём 4+).
- **Поисковые запросы** — аналог «Эффективности» Google.
- **Диагностика** — ошибки обхода, проблемы с sitemap/robots.
- **Товары и цены / Разметка** — проверка нашей Schema-разметки.

## 3. Быстрый чек-лист «после деплоя»

- [ ] Прод открывается на `https://kotcode.dev`.
- [ ] Env в Vercel Production: `GOOGLE_SITE_VERIFICATION`, `YANDEX_VERIFICATION`
      (+ `TELEGRAM_*`, `NEXT_PUBLIC_YANDEX_METRICA_ID`) → Redeploy.
- [ ] Google: ресурс подтверждён, sitemap отправлен, страницы услуг —
      «Запросить индексирование».
- [ ] Яндекс: сайт подтверждён, sitemap добавлен, регион = Брест,
      связка с Метрикой.
- [ ] `curl` показывает оба verification-мета на проде.
- [ ] Rich Results Test (https://search.google.com/test/rich-results)
      по главной и по `/landing` — видит `Service`/`FAQPage`/`LocalBusiness`
      без ошибок.

## 4. Ритм после запуска

- Первая неделя: проверить, что подтверждение прошло и sitemap прочитан.
- Раз в 1–2 недели: «Эффективность» (Google) и «Поисковые запросы» (Яндекс) —
  какие запросы приводят показы, где позиции у страниц услуг.
- По мере роста: добавлять страницы под запросы, которые уже приносят
  показы, но с низкой позицией.
